# SubSplit

> 双语字幕分离与内封字幕提取工具

把中英双语字幕（ASS）一键拆成**纯中文**或**纯英文**字幕，并支持从视频文件中提取内封（软）字幕轨。提供图形界面和命令行两种方式。

---

## 功能特性

- **中/英分离**：从 `中文\N英文` 结构的双语 ASS 字幕中，分离出纯中文或纯英文字幕，时间轴与样式保持不变。
- **格式调节**：可自定义输出字幕的字体、字号、颜色、粗体/斜体、对齐方式、底边距。
- **视频提取**：从 MKV / MP4 / TS 等视频中探测并提取内封软字幕轨（`ass`/`srt`/`mov_text`），提取后可直接进入分离流程。
- **批量处理**：支持单个文件或整个目录。
- **双入口**：图形界面（`subsplit_gui.py`）+ 命令行（`subsplit.py`）。
- **智能识别**：只提取真正的双语对白，自动丢弃画面注释、片头片尾名单、特效等干扰内容。

## 环境要求

| 依赖 | 说明 |
|---|---|
| Python 3.8+ | 核心运行环境 |
| tkinter | GUI 所需（Windows/macOS 的 Python 通常自带） |
| ffmpeg（含 ffprobe） | **可选**，仅「从视频提取字幕」功能需要 |

安装 ffmpeg（Windows）：

```bash
winget install ffmpeg
```

或从 <https://www.gyan.dev/ffmpeg/builds/> 下载预编译包，解压后把 `bin` 目录加入 PATH，或在 GUI 的「ffmpeg」栏填入该目录。

## 快速开始

### 图形界面

```bash
python subsplit_gui.py
```

1. 在「输入」选择字幕文件或目录；
2. 选择「仅英文」或「仅中文」；
3. （可选）调节字体、字号、颜色等；
4. 点击「开始转换」。

如需从视频提取字幕：在「从视频提取字幕」区选择视频 → 探测字幕轨 → 选轨 → 提取，提取出的字幕会自动填入「输入」。

### 命令行

```bash
# 提取英文（默认）
python subsplit.py 字幕.ass

# 提取中文
python subsplit.py 字幕.ass --mode zh

# 批量处理整个目录
python subsplit.py 字幕目录 --mode en

# 指定输出目录
python subsplit.py 字幕目录 --mode zh 输出目录
```

输出文件名会带上语言标记：`原名.英.ass` 或 `原名.中.ass`。

## 支持的双语格式

工具识别的是以下结构（常见于网飞双语字幕）：

```ass
Dialogue: 0,0:00:01.00,0:00:03.00,Default,,0,0,0,,你好，欢迎。\N{\fn微软雅黑\fs80\i1\c&H999999&}Hello, welcome.
```

- `\N` 之前是中文，之后是英文；
- 英文由特效标签 `{\fn微软雅黑...\i1...}` 标记。

分离结果：

| 模式 | 结果 |
|---|---|
| 英文 | `Hello, welcome.`（丢弃纯中文行） |
| 中文 | `你好，欢迎。`（保留纯中文行） |

> 如果字幕不是这种标记方式，工具可能无法正确识别。参见 `sample/bilingual_sample.ass` 里的标准示例。

## 从视频提取字幕的说明

- 只能提取**内封软字幕**（视频容器里独立的字幕轨）。
- 图形字幕（PGS/DVD，即烧录型位图轨）无法直接转文本，工具会提示需 OCR，不在本工具范围内。
- 硬字幕（直接烧在画面像素里的字幕）同样不在本工具范围内。
